# Daily Flow

jag skulle vilja att du hjälper mig att bygga upp en hemsida som ska hjälpa mig att skapa struktur och ordning i min vardag. tanken är att denna sida ska hantera att göra, påminnelser och rutiner för mig, t.ex. hudvårdsrutin eller kvällsruting. den ska ersätta microsoft to do som jag använder i nuläget, men vill alltså utvidga funktionlitet som to do har.

jag har troligtvis en npf diagnos (adhd/autism) och har problem med de exekutiva funktionerna vilket försvårar min vardag. därför vill jag att hemsidan ska vara anpassad efter detta. jag ser framför mig mycket visuell progress och nudging för att främja att alla uppgifter avklaras varje dag. 

det är viktigt att den fungerar väldigt smidigt på telefonen och jag vill inte att sidan ska vara alltför komplicerad.

kan du hjälpa mig planera hur detta kan se ut och ta fram ett utkast?
